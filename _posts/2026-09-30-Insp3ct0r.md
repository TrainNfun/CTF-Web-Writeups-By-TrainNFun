## Solution
The solution is very simple. All you have to do is use the Inspect tool from any browser you have (this can usually be done by using Right Click + Q or Right Click + the "Inspect" section).

### Testing out
First off, check out the website and see if we have any clues to go forward:

By testing out the functionality of the web, we can see that in the "How" section, the creator obviously tells us what has been used to make this website.

<img width="1897" height="398" alt="Inspector_check02" src="https://github.com/user-attachments/assets/4d8c7cae-b8f1-4967-a11a-4ebbe2bb0740" alt="second step"/>
